# Anatomía de una gráfica — Explorador interactivo

**Explorador interactivo** (HTML, funciona sin conexión) que guía un miniproyecto científico de graficación con Python (NumPy + matplotlib): la profundidad de piel δ(f) para varios materiales · **ENES Juriquilla, UNAM**.

🔗 **Portal en línea:** https://elodiestrupiechonski.github.io/anatomia-grafica-explorador/

## Contenido

`anatomia_grafica_interactivo.html` — seis pestañas; cada una modifica la gráfica en vivo y muestra el código de matplotlib correspondiente:

1. **Función** — de la ecuación δ = 1/√(π f μ₀ μr σ) a `def delta(...)`
2. **Frecuencias** — rango, número de puntos, `np.linspace` vs `np.logspace`
3. **Materiales** — casos editables (σ, μr, color, línea, marcador)
4. **Ejes y escala** — título, unidades, lineal/log, línea de referencia
5. **Leyenda y estilo** — `loc`, rejilla, `lw`, `markevery`, `savefig`
6. **Script y retos** — script completo descargable y seis retos

Punto de partida: `index.html`.
